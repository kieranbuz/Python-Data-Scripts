# Project Notes — Python-Data-Scripts

## 2026-08-10 — Initial standardization

**Status:** Production-deployed scripts used in live business operations.

**Projects:**
- Customer Loyalty Points Engine (Python, Pandas) — live at Discover Diving since 2022

**Architecture:**
- Two versions: v1 (original iterative approach), v2 (refactored vectorised Pandas)
- CSV-based input/output (no database)
- Pandas for data aggregation and reconciliation

**Key decisions:**
- Vectorised approach (v2) over iterative for performance
- CSV as interchange format (matches POS system export/import)
- Points calculation: 2.5% of net sales per customer
- Reconciliation against existing customer file (updates known, zeros out inactive)

**Deployment:**
- Manual script execution (not automated)
- Requires local CSV exports from POS system
- Output: updated customer CSV for POS import

**Notes:**
- Script is live and actively used — changes must be tested thoroughly before deployment
- Customer data is sensitive; handle with care
